Core flow

From knowledge page to formatted `.docx` — no polling, no manual copy.

  1. Open the platform knowledge URL
  2. Walk every paginated action list
  3. Extract methods, endpoints, params & samples
  4. Write `Tools/{platform}-tools.docx`

Smart pagination

Detects how many list pages exist and stops when results end — no hardcoded caps.

Clean extraction

Noise filters drop UI chrome while keeping code blocks, tables, and real headings.

250+ exports

`Tools/` ships with prior catalog runs — GitHub, Slack, Jira, Notion, Stripe, and more.

Stack

Local CLI only — browser automation needs Chrome on your machine.

  • Python 3.10+
  • Selenium
  • ChromeDriver
  • python-docx
